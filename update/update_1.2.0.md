# Update 1.2.0

Tanggal: 9 Agustus 2026

## Pemisahan Data Master dan Verifikasi Data

Navigasi admin kini dipisahkan menjadi dua area.

### Verifikasi Data

- Verifikasi data santri: pemetaan kegiatan absensi.
- Verifikasi ORDA.
- Verifikasi data kamar: kamar dan mapping kode kamar.

### Data Master

- Data santri.
- Data alumni.
- Data ORDA.
- Data ekstrakurikuler (dummy; belum terhubung ke absensi atau rapor).
- Data wisma (menampilkan daftar kamar yang tersedia sampai struktur wisma terpisah tersedia).

Data tidak diubah dalam pembaruan ini; perubahan hanya pada struktur navigasi dan tampilan admin.
