# Update 1.3.3

Tanggal: 10 Agustus 2026

## Pembukaan Akses Rekap Kelas untuk Admin & Label Kode Unit

Pembaruan aksesibilitas menu Rekap Kelas dan kejelasan navigasi.

- **Akses Role Admin**: Membuka akses navigasi sidebar, mobile bottom nav, dan route `/rekap-kelas` untuk akun bertipe **Admin**.
- **Label Kode Unit pada Dropdown**: Menambahkan awalan Kode Unit (contoh: `[SMA] 10 IPA 1`, `[MA] 1A`, `[SMP] 7A`, `[SMPT] 1A`) pada pilihan dropdown Rekap Kelas untuk memudahkan pemantauan lintas unit oleh Admin.
- **Penyelarasan Deskripsi Halaman**: Memperbarui meta deskripsi dan petunjuk halaman Rekap Kelas agar relevan bagi Admin dan Wali Kelas.
